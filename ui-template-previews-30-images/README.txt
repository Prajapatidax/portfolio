RESPONSIVE UI TEMPLATE PREVIEWS
10 original fictional design concepts, 3 separate viewport images per concept.

CONTENTS
30 PNG image files + this README.txt = 31 files in this archive.
Missing images: none.

EXPORT DIMENSIONS
Laptop: 1920 x 1200 px, 16:10 landscape (10 files).
Tablet: 1600 x 1200 px, 4:3 landscape (10 files).
Mobile: 1080 x 2340 px, 9:19.5 portrait (10 files).

PRODUCTION NOTES
All 30 files contain actual generated interface artwork. They are static raster concepts.
Each laptop image was generated first. Tablet and mobile images were generated separately using that laptop image as the visual reference.
Generation used the built-in image generation tool. A targeted dashboard revision changed the churn improvement badge to green.
Native generated sizes were 1586 x 992 (laptop), 1448 x 1086 (tablet), and 830 x 1896 (mobile).
Final files were resampled with Lanczos to the exact requested export dimensions, preserving all content without cropping.
Consequently the exports are enlarged, and the mobile canvas has a slight aspect-ratio normalization. They are not native-resolution 1920/1600/1080 px renders.
Brands, people, projects, prices, reviews and dashboard data are fictional demonstration content.
The contact sheet is supplied separately so this ZIP contains exactly 30 images plus this README.

VERIFICATION
All PNGs decode, have their specified dimensions, contain non-uniform image data, and have distinct SHA-256 hashes.
The ZIP was reopened and CRC-tested after creation; its file inventory was checked against all 30 exact filenames.
